Bot settings

One Discord application provides both the bot and the member login.

  1. Open discord.com/developers/applications and create an application. Its Application ID is on General Information.
  2. Under OAuth2, copy the Client Secret and add this redirect exactly:
    {{ callback_url }}
  3. Under Bot, reset and copy the token. No privileged intents are needed.
  4. In Discord, turn on Developer Mode (User Settings → Advanced), then right-click your server and copy its Server ID.

The secret and token are stored encrypted and never shown again.
