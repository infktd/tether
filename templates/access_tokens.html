Access tokens

Tokens let bots and scripts use Tether's API as you: send one as Authorization: Bearer …. A token does only what you tick, only while you still may, and only on the admin API (and reading your account). It never works on pages, and can't change your main, your EVE tokens, your groups or other tokens.
