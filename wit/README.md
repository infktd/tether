# Tether's app interface

`plugin.wit` is the interface between Tether and its apps (`tether:plugin`).
It is licensed under MIT or Apache-2.0, at your option (`LICENSE-MIT`,
`LICENSE-APACHE`), like the SDK in `crates/plugin-sdk`, so apps built
against it can use any license. The rest of Tether is GPL-2.0-or-later.
